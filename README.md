# TCAC Website

A responsive Khmer-language starter website for Taiba Charity Association of Cambodia (TCAC).

## Files
- `index.html` — website structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/tcac-logo.png` — logo supplied in the chat

## Run locally
Open `index.html` in a browser. No build tools are required.

## Before publishing
Replace all square-bracket placeholders and add verified official information:
1. Approved association history, vision, mission, values and leadership details.
2. Actual programs, project photos and activity outcomes.
3. Annual reports, audited financial reports and research PDFs.
4. Official donation QR code and bank account details.
5. Office address, phone, email, social links and a Google Maps embed/link.

The current page intentionally does not invent official contact, financial, governance or project details.
